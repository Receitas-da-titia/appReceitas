# 📋 Requisitos do Sistema

## ✅ Requisitos Funcionais

### RF01 – Cadastro de Usuários
O sistema deverá permitir o cadastro de usuários com nome, e-mail e senha.

### RF02 – Login de Usuários
O sistema deverá permitir autenticação através de e-mail e senha.

### RF03 – Cadastro de Receitas
O sistema deverá permitir cadastrar receitas contendo:
- nome da receita;
- ingredientes;
- modo de preparo;
- categoria;
- tempo de preparo;
- imagem ilustrativa (opcional).

### RF04 – Edição de Receitas
O sistema deverá permitir editar receitas cadastradas.

### RF05 – Exclusão de Receitas
O sistema deverá permitir remover receitas cadastradas.

### RF06 – Busca de Receitas
O sistema deverá permitir buscar receitas por:
- nome;
- ingrediente;
- categoria.

### RF07 – Visualização de Receitas
O sistema deverá exibir detalhes completos das receitas cadastradas.

### RF08 – Sistema de Favoritos
O sistema deverá permitir adicionar receitas à lista de favoritos.

### RF09 – Remoção de Favoritos
O sistema deverá permitir remover receitas da lista de favoritos.

### RF10 – Área Logada
O sistema deverá disponibilizar uma área exclusiva para o usuário autenticado visualizar suas receitas favoritas.

### RF11 – Organização por Categorias
O sistema deverá organizar receitas em categorias culinárias.

### RF12 – Controle Administrativo
O administrador deverá possuir permissões para:
- editar receitas;
- excluir receitas;
- gerenciar conteúdos inadequados.

### RF13 – Logout do Sistema
O sistema deverá permitir que o usuário encerre sua sessão com segurança.

---

# 🛠️ Requisitos Não Funcionais

### RNF01 – Responsividade
O sistema deverá funcionar corretamente em computadores, tablets e smartphones.

### RNF02 – Usabilidade
O sistema deverá possuir interface intuitiva, simples e de fácil navegação.

### RNF03 – Desempenho
As buscas e carregamentos de receitas deverão ocorrer em até 3 segundos em condições normais.

### RNF04 – Compatibilidade
O sistema deverá ser compatível com os principais navegadores modernos.

### RNF05 – Segurança
As senhas dos usuários deverão ser armazenadas utilizando criptografia.

### RNF06 – Controle de Acesso
O sistema deverá restringir funcionalidades administrativas apenas ao perfil de administrador.

### RNF07 – Disponibilidade
O sistema deverá permanecer disponível continuamente, exceto em períodos de manutenção.

### RNF08 – Escalabilidade
O sistema deverá suportar crescimento do número de usuários e receitas sem perda significativa de desempenho.

### RNF09 – Manutenibilidade
O código-fonte deverá seguir padrões de organização para facilitar futuras manutenções e atualizações.

### RNF10 – Persistência de Dados
As informações cadastradas deverão ser armazenadas em banco de dados seguro.

### RNF11 – Tema Visual
O sistema poderá oferecer suporte aos modos claro e escuro.

### RNF12 – Confiabilidade
O sistema deverá minimizar falhas e garantir estabilidade durante o uso.

### RNF13 – Backup de Dados
O sistema deverá realizar backups periódicos das informações armazenadas.

### RNF14 – Interface Visual
O sistema deverá apresentar design moderno e organizado para melhorar a experiência do usuário.
